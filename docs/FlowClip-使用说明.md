# FlowClip 使用说明

## 1. 产品概览

FlowClip 是一款 Windows 桌面效率工具。它常驻系统托盘，帮助你快速找回剪贴板历史、管理常用短语、翻译文本，以及把语音转写成可复制的文字。

适用人群：

- 客服和运营: 快速调用常用回复和模板。
- 写作者和研究人员: 临时收集资料、翻译片段、整理语音笔记。
- 开发者: 保存常用命令、片段和复制历史。
- 普通办公用户: 减少重复输入，找回被覆盖的剪贴板内容。

## 2. 安装与启动

1. 双击安装包 `FlowClip-Setup-1.0.0.exe`。
2. 按提示完成安装。
3. 安装后 FlowClip 会启动并显示主窗口。
4. 关闭主窗口不会退出程序，FlowClip 会继续常驻托盘。
5. 如需完全退出，在系统托盘图标上右键，选择「退出」。

## 3. 主窗口

主窗口左侧是功能导航：

- 剪贴板: 查看和复制历史记录。
- 快捷短语: 管理常用短语分组。
- 翻译: 输入文本并获取翻译结果。
- 语音转写: 录音并转成文字。
- 设置: 修改主题、快捷键、存储位置和启动选项。

## 4. 剪贴板历史

FlowClip 会自动监听系统剪贴板，记录以下类型：

- 文本
- 链接
- 图片
- 文件路径

常用操作：

1. 在「剪贴板」页面顶部搜索内容。
2. 使用筛选标签查看指定类型。
3. 点击一条记录即可重新复制到系统剪贴板。
4. 点击图钉按钮可以置顶常用记录。置顶记录会保留在列表顶部，并且不会因为保留时间或最大记录数自动清理。
5. 点击记录右上角删除按钮可以删除单条记录。
6. 点击清空按钮后需要再次确认。确认后会删除全部历史，置顶记录也会被删除。

注意：文件类型会复制文件路径文本，而不是还原成真正的文件拖放对象。

敏感内容保护：

- FlowClip 默认不会保存疑似密码、Token、API Key、访问密钥和带敏感参数的链接。
- 这个功能只影响剪贴板历史记录，不会阻止你在其他软件中正常复制和粘贴。
- 如需记录这类内容，可以在「设置」里关闭「敏感内容保护」。

## 5. 快捷短语

快捷短语用于保存经常输入的文本，例如客服回复、常用命令、邮件模板。

常用操作：

1. 在「快捷短语」页面创建分组。
2. 在分组下新增短语。
3. 点击短语卡片即可复制内容。
4. 可以编辑、删除短语和分组。
5. 点击工具栏的导出按钮，可以把当前短语库保存为 FlowClip JSON 文件。
6. 点击导入按钮，可以把另一个 FlowClip 短语库合并进当前短语库。导入不会覆盖已有内容，重复短语会自动跳过。

短语变量：

- 新建或编辑短语时，可以点击变量按钮插入变量。
- `{{date}}`: 当前日期，例如 `2026-06-02`。
- `{{time}}`: 当前时间，例如 `14:30`。
- `{{datetime}}`: 当前日期和时间。
- `{{weekday}}`: 当前星期。
- `{{clipboard}}`: 复制短语前的当前剪贴板文本。
- 变量会在点击短语复制时自动展开，短语库中仍保留原始模板。

建议用法：

- 按使用场景分组，例如「客服回复」「开发命令」「邮件模板」。
- 给短语添加备注，方便区分相似内容。
- 在日报、邮件和客服模板中使用变量，例如 `今天是 {{date}}，当前剪贴板内容是：{{clipboard}}`。
- 定期导出短语库，方便迁移到其他电脑或备份团队常用回复。

## 6. 翻译

FlowClip 支持两种翻译方式：

- Google: 可不填 API Key，但稳定性取决于网络环境。
- AI: 使用 OpenAI-compatible 接口，例如 DeepSeek。

使用方法：

1. 打开「翻译」页面。
2. 输入要翻译的文本。
3. 选择目标语言。
4. 点击「翻译」。
5. 点击复制按钮，把结果写入系统剪贴板。

AI 翻译配置：

- 服务商预设: 可选 DeepSeek、Google 免费接口或 OpenAI-compatible 自定义。预设只会填入地址、模型和默认引擎，不会覆盖 API Key。
- API 地址: 例如 `https://api.deepseek.com`。如果服务商文档给的是 `https://api.example.com/v1`，也可以直接填写，FlowClip 会自动避免重复拼接 `/v1`。
- API Key: 你的服务商密钥
- 模型: 例如 `deepseek-v4-flash`
- 代理地址: 可选，格式类似 `http://127.0.0.1:7890`

点击「测试连接」可用当前草稿发送极短文本，确认 API 地址、Key、模型和代理是否可用；结果会解释常见 HTTP 错误，并可复制不含 API Key 的脱敏诊断。

## 7. 语音转写

语音转写可以把麦克风录音转成文字，并可选用 AI 做断句和术语润色。

推荐配置：

- 服务商预设: SiliconFlow SenseVoice。
- 识别 API 地址: `https://api.siliconflow.cn/v1`
- API Key: 在 `https://cloud.siliconflow.cn/account/ak` 创建或管理
- 模型: `FunAudioLLM/SenseVoiceSmall`
- 语言: 中文，或选择自动检测

SiliconFlow 官网当前标注新用户有启动额度，但语音识别是否免费、额度多少和价格策略都可能变化，请以服务商控制台和价格页为准。

点击「测试连接」会检查模型列表，不会录音或上传音频；结果会显示请求地址、代理、模型列表摘要，并可复制脱敏诊断。

使用方法：

1. 打开「语音转写」页面，或按 `Ctrl+Alt+V` 呼出语音浮窗。
2. 点击麦克风开始录音。
3. 再次点击停止录音并开始识别。
4. 等待识别结果出现。
5. 点击「复制」或「复制并关闭」。

术语润色：

- 开启后，FlowClip 会使用 AI 对识别结果断句、补标点和修正术语。
- 这个功能会复用「翻译」里的 AI API Key。
- 如果你只想减少额外 AI 调用，可以关闭术语润色；语音识别本身仍会使用你配置的 ASR 服务额度。

## 8. 快捷面板

默认按 `Ctrl+Alt+Space` 可以呼出快捷面板。它适合在其他软件里快速找内容，不必先切回 FlowClip 主窗口。

常用操作：

1. 在顶部输入关键词，搜索当前剪贴板历史或快捷短语。
2. 使用上方标签切换「全部」「文本」「链接」「图片」「文件」等剪贴板类型。
3. 切到「快捷短语」后，可以按分组筛选短语。
4. 点击条目，或使用方向键选择后按 `Enter`，即可复制到系统剪贴板。

自动粘贴：

- 在「设置」中开启「快捷面板自动粘贴」后，选中条目会先复制，再尝试粘贴到当前活动窗口。
- 这个功能默认关闭，适合客服回复、表单填写、聊天窗口等高频场景。
- 自动粘贴依赖 Windows 当前前台窗口焦点，如果目标软件拦截粘贴快捷键，可能只会完成复制。

## 9. 快捷键

默认快捷键：

- `Ctrl+Alt+Space`: 呼出快捷面板。
- `Ctrl+Alt+V`: 呼出语音转写浮窗。

修改方法：

1. 打开「设置」。
2. 找到对应快捷键设置。
3. 点击快捷键按钮。
4. 按下新的组合键。

如果快捷键注册失败，通常是被其他软件或输入法占用。FlowClip 会自动切到「设置」页，并在顶部显示冲突提示。请在对应快捷键项里换一个组合键。

## 10. 设置

可配置项：

- 深色模式
- 窗口置顶
- 开机自启
- 快捷面板自动粘贴
- 快捷面板快捷键
- 语音转写快捷键
- 剪贴板保留时间
- 最大记录数量
- 敏感内容保护
- 数据存储位置
- 帮助与文档入口

数据默认保存在应用数据目录。你也可以在设置中选择自定义目录，或点击「打开」直接查看当前数据目录。「帮助与文档」可以打开随安装包附带的 PDF 用户手册和发布说明，也可以复制脱敏应用诊断信息，便于排查版本、系统、快捷键和配置问题。

## 11. 常见问题

### 点击复制后没有复制成功

请安装最新版本。新版已经把复制操作统一改为 Electron 主进程写入系统剪贴板，并会在写入后回读校验。如果仍失败，请检查是否有安全软件拦截剪贴板访问。

### 快捷面板自动粘贴没有反应

请先确认「设置」里的「快捷面板自动粘贴」已经开启。FlowClip 会在关闭快捷面板后尝试向当前前台窗口发送粘贴快捷键；如果目标软件没有获得焦点、以管理员权限运行，或拦截了粘贴快捷键，可能需要手动按 `Ctrl+V`。

### 语音转写提示缺少 API Key

打开「语音转写 - 设置」，填写服务商 API Key。SiliconFlow 的 API Key 可以在 `https://cloud.siliconflow.cn/account/ak` 创建或管理。

### AI 术语润色不能用

术语润色依赖「翻译」里的 AI API Key。请先在翻译设置中填写 API 地址、API Key 和模型，或关闭术语润色。

### 不确定 API 配置是否正确

打开对应设置弹窗，点击「测试连接」。诊断明细会提示 API 地址、Key、模型名、代理、额度或权限问题；需要别人帮忙时点击「复制诊断」，但不要手动粘贴完整 API Key。

### 快捷键没有反应

可能原因：

- 快捷键被其他软件占用。
- FlowClip 没有在后台运行。
- 系统安全策略限制全局快捷键。

解决方法：

1. 打开主窗口进入「设置」。如果 FlowClip 检测到注册失败，通常会自动切到这里。
2. 查看顶部冲突提示，确认失败的组合键。
3. 换一个快捷键。
4. 从托盘菜单重新打开 FlowClip。

### 关闭窗口后程序还在运行

这是正常行为。FlowClip 是托盘常驻工具。要退出，请右键托盘图标并选择「退出」。

## 12. 隐私说明

- 剪贴板历史、短语和设置默认保存在本机。你可以在「设置」里打开当前数据目录。
- 「敏感内容保护」默认开启，会让疑似密码、Token、API Key 和敏感链接参数不进入剪贴板历史。
- 翻译和语音转写会把你提交的文本或音频发送到你配置的 API 服务商。
- 如果内容涉及密码、令牌、合同或隐私信息，请谨慎使用第三方 API。
