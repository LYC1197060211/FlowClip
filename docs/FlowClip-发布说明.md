# FlowClip 1.0.0 发布说明

发布日期：2026-06-02

## 交付产物

- Windows 安装包：`release/FlowClip-Setup-1.0.0.exe`
- PDF 用户手册：`output/pdf/FlowClip_User_Guide.pdf`
- 安装包 SHA256 校验文件：`release/FlowClip-Setup-1.0.0.exe.sha256.txt`

## 本版定位

FlowClip 1.0.0 是面向 Windows 桌面用户的首个成熟化交付版本。它将剪贴板历史、快捷短语、翻译和语音转写放在一个常驻托盘工具中，重点解决高频复制、找回、转写、翻译和模板化输入的问题。

## 主要更新

- 产品品牌统一为 FlowClip，安装包、窗口标题、托盘提示和应用图标已同步更新。
- 修复语音转写浮窗「复制并关闭」复制失败的问题，复制统一走 Electron 主进程剪贴板并回读校验。
- 快捷面板支持搜索剪贴板历史和快捷短语，并可选开启选中后自动粘贴到当前活动窗口。
- 剪贴板历史支持置顶，置顶项优先展示并跳过自动清理。
- 快捷短语支持变量：`{{date}}`、`{{time}}`、`{{datetime}}`、`{{weekday}}`、`{{clipboard}}`。
- 快捷短语库支持导入和导出，导入采用合并策略并跳过重复短语。
- 翻译和语音转写设置增加「测试连接」，保存前即可检查 API、模型和代理配置。
- 语音转写支持 SiliconFlow `FunAudioLLM/SenseVoiceSmall`，可选 AI 术语润色。
- 设置页支持打开当前数据目录，便于备份、排查和迁移。
- 默认开启敏感内容保护，疑似密码、Token、API Key 和敏感 URL 参数不会进入剪贴板历史。
- 全局快捷键注册失败时，会自动进入设置页并提示更换组合键。
- 新增 `npm run smoke` 自动化交付烟测，用于校验安装包、SHA256、PDF 手册和关键复制链路。
- 翻译和语音「测试连接」新增诊断明细，可显示请求地址、代理状态、模型列表摘要和常见 HTTP 错误解释。
- 诊断明细支持一键复制为脱敏报告，方便排查 API 配置时转发给协助者。
- AI 翻译地址兼容带 `/v1` 或不带 `/v1` 的 OpenAI-compatible 写法，避免重复拼接路径。
- 翻译和语音设置新增服务商预设，可快速填入 DeepSeek、Google、SiliconFlow 或自定义兼容接口配置。
- DeepSeek 预设更新为 `deepseek-v4-flash`，并使用官方 Chat endpoint 路径。
- 安装包随附 PDF 用户手册和发布说明，设置页新增「帮助与文档」入口，可直接打开。
- 设置页新增「应用诊断信息」复制入口，可复制版本、系统、数据目录、快捷键和配置摘要，不包含 API Key 或剪贴板内容。
- 剪贴板清空确认弹窗强化危险操作提示，清空会删除全部历史和置顶记录；通用弹窗增加键盘聚焦、Esc 关闭和读屏属性。

## 已知限制

- Windows 安装包当前未配置代码签名，因此首次安装时可能出现系统安全提示。
- 文件类型剪贴板记录会复制文件路径文本，不会还原为可拖放的文件对象。
- 自动粘贴依赖当前前台窗口焦点，若目标软件拦截粘贴快捷键，可能只会完成复制。
- SiliconFlow、DeepSeek 等第三方服务的免费策略、模型列表和价格可能变化，请以服务商控制台为准。
- 发布说明为 Markdown 文件，会使用系统默认关联程序打开。

## 校验方法

在 PowerShell 中运行：

```powershell
Get-FileHash .\release\FlowClip-Setup-1.0.0.exe -Algorithm SHA256
```

将输出的哈希值与 `release/FlowClip-Setup-1.0.0.exe.sha256.txt` 中记录的值比对。

开发环境中也可以运行：

```powershell
npm run smoke
```

该命令会执行只读烟测，确认发布产物存在、哈希一致，并检查语音浮窗「复制并关闭」等关键复制通道没有回退到浏览器剪贴板 API。
